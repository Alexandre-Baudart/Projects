# Project 2: Coronary Disease Prediction

## Description

This project evaluates and compares various machine learning models to predict the presence of 
coronary artery disease in patients. 
Feature importance and the impact of model calibration were also analyzed.

Check out the live demo **[here](https://heart-disease-prediction-project-demo.streamlit.app/)**.

Check out the report **[here](report.pdf)**.

## Models Evaluated
* Logistic Regression
* SVM
* Random Forest
* XGBoost
* CatBoost
* MLP
* Tab-Transformer

## Running the project locally

If you want to run this project on your own computer, check the available options and instructions with option -i:
* For ML session : python -m src.ml.ml_main -i 
* For DL session : python -m src.dl.dl_main -i
